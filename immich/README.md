DO NOT edit files in /opt/immich directly.

Known GPU requirement:

The Intel render group must be added to:

- immich-server
- immich-machine-learning

through:

group_add:
  - "${RENDER_GID}"

Without this, access to:

/dev/dri/renderD128

fails with:

Permission denied
